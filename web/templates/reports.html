Detection Evaluation Note

The current detection system uses a Random Forest classifier trained with 17 handcrafted image features together with OpenCV YuNet face detection. The model's reported evaluation is based on the project's group-aware test split. These evaluation results describe performance on the evaluated dataset and should not be interpreted as guaranteed real-world detection accuracy.
