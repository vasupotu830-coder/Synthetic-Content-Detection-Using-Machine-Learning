System Insights

Current synthetic content detection pipeline.

Detection Engine
Random Forest classifier trained for REAL versus FAKE classification using handcrafted visual features.
Feature Extraction
The image pipeline uses 17 visual features covering brightness, edges, sharpness, color statistics, gradients, and face characteristics.
Face Analysis
OpenCV YuNet is used for face detection during visual feature extraction.
Video Analysis
Video detection analyzes sampled video frames and aggregates their classification probabilities.
Persistence
Detection results are stored in the MySQL detection history database for reporting and analytics.
